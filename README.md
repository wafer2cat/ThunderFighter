# 雷霆战机 · Thunder Fighter

[English](README.en.md)

一个使用 Python 标准库 `tkinter` 制作的纵版射击小游戏，无需安装 pygame 或其他第三方依赖。

## 启动

在当前目录执行：

```bash
python main.py
```

## 操作

- `WASD` / 方向键：移动战机
- `SPACE` / `J`：射击
- `P`：暂停 / 继续
- `L`：在中文 / English 之间切换界面语言
- `ENTER` / `SPACE`：开始或重新开始
- `ESC`：退出

语言切换会立即更新主菜单、HUD、波次提示、暂停界面和结算界面；游戏状态不会重置。

## 道具与升级

- `BARRIER`：一次性防护屏障，最多持续 10 秒，可抵挡一次伤害后消失，最后 3 秒仅防护光环闪烁。
- `ROCKET`：持续 10 秒，普通子弹之外追加火箭攻击，命中后造成范围爆炸。
- `ENERGY`：为 `SHIELD` 恢复 1 点能量，护盾初始为满值 5/5。
- 击败敌机获得经验：Scout/Zigzag/Tank 分别为 6/10/15，Boss 为 100；每级分别需要 100、250、450、700 点当前经验，升级后经验清零。
- 火力达到 5 级后，每额外获得 250 点经验会直接获得一个随机 `BARRIER`、`ROCKET` 或 `ENERGY`。
- 普通敌机总掉落率为 6%，三类道具各占 2%；Boss 击败后必定掉落随机道具。

## 游戏内容

- 自动生成星空背景和连续敌机波次
- 三类敌机：侦察机、重装机、蛇形机
- 击落敌机有概率掉落 `BARRIER`、`ROCKET` 或 `ENERGY`
- 火力通过经验永久升级，最多五重射击
- 每 5 个波次出现 Boss，并显示 Boss 血条
- 包含生命值、分数、无敌保护、粒子爆炸、屏幕震动和暂停界面
